# FindIt – Lost & Found (demo-mode core)
Requires Node 18+. From this folder: `npm run install:all` then `npm run dev` (http://localhost:5173).
Demo logins: user@demo.com / user123, admin@demo.com / admin123. Data lives in browser localStorage ("Reset demo data" on Dashboard).
